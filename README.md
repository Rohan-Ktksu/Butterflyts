# Butterflyts

Butterflyts is an aviation data research and analytics project focused on
understanding aircraft movements and airport operational conditions using
real-world aviation data.

## Current Development

Initial development currently focuses on Kempegowda International Airport
(BLR / VOBL).

Current capabilities include:

- Airport data ingestion
- Runway geometry extraction
- Live ADS-B data ingestion
- Aircraft position monitoring
- Aircraft altitude, speed, track, and vertical-rate analysis

## Technology

- Python
- Pandas
- NumPy
- PyArrow
- Requests
- Matplotlib

## Project Structure

src/ingestion - Data ingestion tools

src/trajectories - Aircraft trajectory processing

src/weather - Aviation weather processing

src/events - Operational event detection

src/features - Feature engineering

src/models - Machine-learning models

data - Local aviation datasets

research - Research notes and experiments

## Data

Large aviation datasets and generated data are intentionally excluded from
the Git repository.
